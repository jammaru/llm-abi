# 0007 — Qwen tools are not OpenAI strict mode

Date: 2026-08-18

## Decision

The Qwen tools profile is not an OpenAI copy. Official Model Studio docs for JSON Schema mode and function calling list a closed type set:

`string`, `number`, `integer`, `boolean`, `object`, `array`, `enum`

They also document:

- optional fields by omitting them from `required`
- nullable fields as `{"type": ["string", "null"]}`
- `additionalProperties: true` to allow extra fields and `false` to close the object (recommended, not required)

`anyOf`, `oneOf`, `$ref`, `format`, `minLength`, and `prefixItems` are not in that list, so they are not treated as supported. `additionalProperties` is preserved rather than forced false.

## Evidence

`documented` against https://help.aliyun.com/en/model-studio/qwen-structured-output and https://help.aliyun.com/en/model-studio/qwen-function-calling (revision 2026-08).
