# 0006 — xAI Grok is not OpenAI strict mode

Date: 2026-08-18

## Decision

The Grok structured profile is not an OpenAI copy. Official structured-output docs require a different subset:

- `$ref` / `$defs` are non-circular only
- fields omitted from `required` stay optional; `null` uses a type array or `anyOf`
- `additionalProperties` defaults to `false` and must be `true` to open an object
- boolean schemas (`true` / `false`) are rejected, including `items: false`
- `oneOf` is accepted but behaves as `anyOf`
- `allOf` with more than one subschema is best-effort
- `minLength` / `maxLength` are guaranteed only up to 2048; `minItems` / `maxItems` up to 256; `minProperties` / `maxProperties` up to 64
- enforced string formats are `date`, `time`, `date-time`, `email`, `uuid`, `ipv4`, `ipv6`, `uri` — not `hostname`

Emit therefore uses `objectPolicy.additionalProperties: "omit-false"`: keep explicit `true`, omit `false` (the documented default), and rewrite `items: false` to `maxItems` on tuples. Recursive `$ref` is `unsupported`. Constraint values above the documented ceilings become `runtime-only`.

## Evidence

`documented` against https://docs.x.ai/developers/model-capabilities/text/structured-outputs (revision 2026-08).
