# 0010 — MCP tools compile to the host subset, not an MCP SDK

Date: 2026-08-18

## Decision

The MCP tools profile is not a vendor SDK wrapper and not an OpenAI copy. It compiles `inputSchema` to the subset MCP hosts still accept, then reports what that subset cannot represent.

Published MCP `2025-11-25` `Tool.inputSchema` is:

```ts
{
  $schema?: string;
  type: "object";
  properties?: object;
  required?: string[];
}
```

Tool arguments are always objects. Combinators (`oneOf` / `anyOf` / `allOf`), `$ref` / `$defs`, and numeric / `format` constraints are outside that published type.

SEP-2106 (merged 2026-05) widens protocol `inputSchema` to JSON Schema 2020-12 _inside_ the object root. This profile does not claim every host has shipped that draft. Canonical id `mcp/2026-06/tools` is the 2026 host-safe compile; `mcp/2025-11/tools` is an alias for the same profile.

| Surface                             | This profile                                               |
| ----------------------------------- | ---------------------------------------------------------- |
| Root                                | Must be `type: "object"`                                   |
| Optional fields                     | Stay optional (not OpenAI required-all / nullable)         |
| Nested `enum`                       | Kept; hosts already accept it in practice                  |
| Non-recursive `$ref` / `$defs`      | Inlined into a plain object tree so hosts never see `$ref` |
| Recursive `$ref`, `oneOf` / `anyOf` | `unsupported`                                              |
| `minimum`, `format`, `minLength`, … | Stripped from the host schema; kept in `result.validate`   |

Host notes:

- Claude Desktop and Claude Code still commonly reject non-object roots, `$ref`, and `oneOf` when they forward `inputSchema` to a model.
- Other hosts and newer SDKs may accept SEP-2106 combinators. README status is **Partial** because hosts differ.
- `packages/core` must not depend on the official MCP TypeScript SDK. Any MCP server framework can call `compile(schema, "mcp")`.

## Evidence

`documented` against the published MCP `2025-11-25` schema, SEP-2106, and https://modelcontextprotocol.io (revision 2026-08).
