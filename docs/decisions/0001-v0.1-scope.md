# 0001 — v0.1 scope

Date: 2026-08-17

## Decision

Ship a compiler with:

- Input: JSON Schema and Standard JSON Schema
- Targets: OpenAI structured outputs, Anthropic structured outputs, Gemini structured outputs
- API: `compile`, `check`, `analyze`, `fingerprint`
- CLI: `check`, `compile`, `explain`, `doctor`
- Compatibility: `lossless | runtime-safe | lossy | unsupported`

## Why

The empty space is not "convert Zod to OpenAI". It is provider-aware lowering with loss diagnostics. v0.1 stays narrow so the IR and profile format can stabilize.

## Not in v0.1

- DeepSeek, xAI, Qwen, Mistral, OpenRouter, MCP
- Playground
- GitHub Action package
- Compatibility percentages
- Rust
- Runtime provider SDK adapters
